# Diwyashakthi Wedamedura Website

Responsive static website for Diwyashakthi Wedamedura, focused on the Eppawala location.

## Included

- Home, About, Services, Gallery and Contact pages
- Responsive desktop/tablet/mobile navigation
- Luxury Ayurveda-inspired visual design
- Phone and WhatsApp actions
- WhatsApp enquiry form
- Google Maps and Google Reviews links
- SEO titles, descriptions, canonical URLs and LocalBusiness structured data
- robots.txt and sitemap.xml
- Custom 404 page
- GitHub Pages deployment workflow

## GitHub Pages

The deployment workflow is located at `.github/workflows/deploy-pages.yml`.

To activate publishing for the first time, open **Settings → Pages → Build and deployment → Source** and choose **GitHub Actions**. After Pages is enabled, run the `Deploy to GitHub Pages` workflow or push any new commit to `main`.

Expected project URL after successful deployment:

`https://hashansoysa92-commits.github.io/Diwyashakthi/`
